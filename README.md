# 🏙️ 3D Third-Person Simulation Prototype (Unity/C#)

**Project Codename:** The Chaves Village Game (Vila do Chaves/Chavo del Ocho 3D Recreation)

A fully interactive 3D environment developed in **Unity Engine**, featuring third-person character control, NPC AI behaviors, and physics-based interactions. This project serves as a showcase of C# programming logic and game development lifecycle.

## ⚙️ Technical Implementations (C# Scripts)

This repository highlights my ability to write clean, logical code for complex systems:

### 1. AI & Vector Mathematics (`NPC_LookAtPlayer.cs`)
* **Logic:** Implemented vector math to calculate direction and rotation, ensuring NPCs dynamically track the player's position in 3D space.
* **Skills:** `Vector3`, `Quaternion.LookRotation`, `Transform`.

### 2. Event Triggers & Interaction (`OpenDoor.cs`)
* **Logic:** Created proximity triggers using Colliders to execute state changes (opening/closing doors) based on player input or position.
* **Skills:** `OnTriggerEnter`, `Booleans`, `Animator Control`.

### 3. Autonomous Behavior (`Wander.cs`)
* **Logic:** Developed a basic AI routine for NPCs to navigate the environment autonomously using random waypoints.
* **Skills:** `NavMeshAgent`, `Coroutines`, `Randomization`.

## 📂 Project Structure
* **Assets/Scripts:** Contains all C# logic source code.
* **Assets/Scenes:** 3D environment layout and lighting configuration.
